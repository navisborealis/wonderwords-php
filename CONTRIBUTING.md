# Contributing to Wonderwords PHP

First off, thank you for considering contributing to `wonderwords-php`! It's people like you that make the open source community such a great place to learn, inspire, and create.

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an open issue for it. If not, open a new issue to start a discussion.

## 2. Fork & create a branch

If this is something you think you can fix, then fork `wonderwords-php` and create a branch with a descriptive name.

## 3. Implement your fix or feature

At this point, you're ready to make your changes! Feel free to ask for help; everyone is a beginner at first.

## 4. Run the test suite and code style fixer

Before submitting your pull request, please make sure that all tests pass and that your code adheres to our code style guidelines (PSR-12/PHP-CS-Fixer).

### Running Tests

We use PHPUnit for testing. Run the test suite using:

```bash
vendor/bin/phpunit
```

### Running Code Style Fixer

We use `friendsofphp/php-cs-fixer` to enforce coding standards. You can automatically fix style issues by running:

```bash
vendor/bin/php-cs-fixer fix
```

## 5. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with `wonderwords-php`'s master branch.
Then create a pull request with a clear list of what you've done. When you send a pull request, we will review it and merge it!
